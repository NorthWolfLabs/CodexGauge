# Security policy

## Supported versions

Security fixes are provided for the latest published CodexGauge release.

## Report a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub’s **Security > Report a vulnerability** flow in `NorthWolfLabs/CodexGauge` so the report and any proof of concept remain private.

Include the affected version, macOS version, impact, reproduction steps, and any suggested mitigation. North Wolf Labs will acknowledge a complete report within seven days and will coordinate disclosure after a fix is available.

CodexGauge is read-only by design. Reports involving credential disclosure, unsafe rollout parsing, executable substitution, release-signing compromise, or notification privacy are especially important.
