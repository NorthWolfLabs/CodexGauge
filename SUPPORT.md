# Support

For setup questions and reproducible bugs, open an issue at `NorthWolfLabs/CodexGauge` using the appropriate template. Search existing issues first.

Include the CodexGauge version, Mac model, macOS version, ChatGPT/Codex version, whether the task ran on this Mac, and the exact user-visible error. Never attach Codex session files, credentials, private keys, prompts, answers, or command output.

Security concerns belong in a private vulnerability report as described in [SECURITY.md](SECURITY.md).
